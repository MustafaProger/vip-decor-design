## Навигация

Позиция прокрутки и число загруженных карточек сохраняются для конкретного посещения и URL. Возврат через браузер и ссылку «Вернуться к каталогу» восстанавливает каталог вместе с фильтрами. Перезагрузка после возврата использует последнее положение пользователя. Новые страницы каталога не наследуют состояние другой категории.

Проверки Chrome при ширине 1440 и 390 px:

- 72 загруженные карточки → товар → назад: точное восстановление позиции;
- возврат по ссылке из карточки товара;
- перезагрузка каталога после дальнейшей прокрутки;
- 48 карточек отфильтрованного каталога → товар → перезагрузка товара → назад: сохранены URL, фильтры, число карточек и позиция;
- поиск Cresha → товар → смена цвета → перезагрузка → ссылка возврата: сохранены поисковый URL и прежняя позиция.

Результаты: `scroll-qa.json`. Дополнительно в браузере проверены новые фотографии «Лабиринт» и «Замша», а также отсутствие метки HDR в миниатюре и увеличенном фото отзыва. Основной набор: 85 тестов без ошибок. Отдельный тест миграции проверяет dry-run, повторное применение, восстановление исходных URL из резервной копии, в том числе для алиасов, сохранение заявок и изменённых после миграции цен. Production-сборка проходит. Изолированный состав коммита без прежних изменений Метрики: 80 тестов и сборка также проходят.

## Миграция и выпуск

`scripts/migrate-clean-media.py` по умолчанию выполняет dry-run. `--apply` создаёт SQLite backup с правами 0600 и транзакционно заменяет только точные URL в сущностях и метаданных контента. Остальные поля сохраняются; версии изменённых сущностей увеличиваются. `--restore-from <backup>` возвращает только ранее заменённые URL, сохраняя прочие последующие изменения.

Изменены ссылки в 162 товарах и метаданных контента. Серверная миграция применена к актуальной базе `/var/lib/vipdecor/runtime/cms.sqlite`; локальная база на сервер не переносилась.

Выполнена публикация `/opt/vip-decor/releases/20261105-media-scroll` с последующим выпуском `20261105-media-scroll-variant`: проверка контрольных сумм текущего выпуска, штатная резервная копия, отдельная директория, миграция, переключение симлинка и перезапуск. При ошибке предусмотрен откат ссылок и предыдущего выпуска. Архив, скрипт и контрольные суммы находятся в `outputs/media-audit-20261104/`.

Предшествующие незакоммиченные изменения Метрики и форм сохранены отдельно и не включаются в коммит этой задачи. Они присутствовали в рабочем окружении и в ранее проверенной версии сервера.
