# Акция «Возврат 15% за рекомендацию» — 31 октября 2026

## Согласованное предложение

Возвращается 15% суммы собственного заказа клиента, который привёл нового
клиента. Приглашённый клиент должен оформить заказ в течение одного месяца
с даты оформления заказа рекомендателя. Если в этот срок нового заказа нет,
возврат по акции не начисляется.

Срок перечисления, способ выплаты, лимиты и сочетание с другими предложениями
владелец не определял: сайт предлагает уточнить детали у менеджера. Автоматических
начислений, выплат и изменения суммы корзины нет.

## Размещение

- Главная: блок после отзывов, перед статьями.
- Каталог и категории: компактный анонс после навигации по категориям.
- Карточка товара и непустая корзина: ссылка с условиями в краткой форме.
- `/referral`: предложение, пример 100 000 ₽ → 15 000 ₽, три шага,
  раскрывающиеся вопросы, форма обращения к менеджеру.
- Ссылки в подвале и HTML/XML-картах сайта, отдельные title/description/canonical.

Использованы существующие цвета, шрифты, кнопки и Reveal-анимации. Эти анимации
учитывают prefers-reduced-motion; CSS-переходы нового блока тоже отключаются
при соответствующем предпочтении. Отдельная ручная проверка системного режима
уменьшения движения не выполнялась.

Форма использует существующий механизм заявки и передаёт менеджеру контекст
акции с месячным сроком. Новых полей с контактами третьих лиц нет.

## Проверки

- Production/SSR build успешен; сохранено стандартное предупреждение Vite о
  размере основного JS >500 kB.
- Локально: все 85 Node-тестов прошли.
- Браузер Chrome: 30 сочетаний пяти страниц с ширинами 320, 360, 390, 768,
  1024, 1440 CSS px. Горизонтального переполнения страницы и новых блоков нет.
- Проверены переходы из каталога/корзины, добавление товара, сохранение суммы
  корзины 3 390 ₽, все шесть раскрывающихся ответов, валидация формы.
- Одна вымышленная заявка создана только в изолированном локальном runtime:
  контекст акции сохранён. Реальные заявки/письма на рабочем сайте не создавались.
- Анимация страницы проверена: opacity 0 → 1, translateY(28px) → none.
- На действующем сервере: 20 сочетаний пяти страниц с ширинами 320, 390, 768,
  1440 плюс четыре проверки непустой корзины. Переполнения и console errors нет.
  Открытие формы передаёт актуальный контекст; production POST не выполнялся.
- Новая страница и 13 других HTML/API/XML-адресов: HTTP 200 через HTTPS nginx.
  Все 19 JS/CSS-ресурсов клиента прочитаны по HTTPS с проверкой TLS, SHA-256
  совпадают с локальной сборкой; `/referral` присутствует в XML-карте сайта.
