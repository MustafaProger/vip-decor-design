# Проверка CMS — 19 сентября 2026

Проверена локальная сборка VIP Decor Design. Production-хостинг не проверялся и не изменялся.

- `npm test`: 55/55 тестов.
- `npm run build`: TypeScript, клиентская сборка, HTML блога и SSR bundle успешно.
- `npm run qa:cms`: 14 успешных сценариев на настоящем сервере с отдельной временной базой: первый вход, 477 товаров/3 статьи, черновики, публикация, редакторы, загрузка фото, заявка с сайта, закрытый доступ, перезапуск и сохранность состояния.
- 14 замеров основных экранов и редакторов на 320/390/768/1440 CSS px; горизонтального переполнения документа нет, таблицы прокручиваются внутри контейнера.
- Автоматический Axe WCAG A/AA для списка заявок — без нарушений; ошибок JavaScript нет.
- Регрессия существующего блога на dev-сервере: 7 страниц читаются без JS, 40 замеров, 8 Axe-сканирований, метаданные, JSON-LD, sitemap, 404/301, оглавление, категории и 12 редакционных ссылок — успешно.
- Рабочая CMS запущена на `http://127.0.0.1:5180/admin`. Отдельно проверен первый вход в dev/StrictMode: одноразовый ключ заполняет форму, URL-фрагмент удаляется. Рабочий администратор автоматически не создавался.

Все показанные контакты и учётная запись `cms-qa-admin` — вымышленные данные из удалённой временной базы. Рабочая CMS не содержит тестовых товаров и заявок этой проверки.
