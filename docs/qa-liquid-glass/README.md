## Сравнение с макетами

- Контакты: сохранены композиция из фото и контактной карточки, тёплый фон, зелёный акцент и стеклянная навигация. Реальная фотография работы компании заменяет сгенерированное изображение шоурума из макета. Адрес ведёт в Яндекс Карты; схематическая карта не используется как географический факт.
- Прайс: читаемая плотная поверхность, категории, правое выравнивание цен и крупное фото с карточкой расчёта. Показаны все 10 позиций источника. Цифры набраны интерфейсной гарнитурой для ясности.
- Гид: выбор комнаты, тематическая фотография исходного гида, три кратких ориентира, категории материалов и консультация. Полный исходный текст раскрывается под карточкой. Дополнительные советы о карнизах и жалюзи доступны ниже.
- На мобильных страницы перестраиваются по назначению: контакты и действия перед фотографией, прайс без горизонтального скролла, переключатели комнат переносятся на несколько строк.
