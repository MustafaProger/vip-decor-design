# Готовность к публикации

Реализованы сайт, каталог, блог, калькулятор, корзина и CMS для статей, товаров и заявок. Каталог и блог импортируются один раз; изменения CMS хранятся на сервере и доступны без повторной сборки. Публикация на домене и production-интеграции требуют отдельной проверки.

## Оставшиеся зависимости

| Область | Что требуется |
| --- | --- |
| Размещение | Node.js 24.15+, постоянная папка данных, HTTPS proxy, домен и проверка после развёртывания |
| Контент | Подтвердить актуальность цен, вариантов, коммерческих условий и исходных текстов |
| Формы | Обращения уже доступны в CMS; для уведомлений нужен согласованный канал доставки и проверка реального обмена |
| Магазин | Серверная проверка остатков и цен, создание заказа и подключение платежей |
| Аналитика | Подтвердить счётчик и необходимые события |
| Изображения | Заменить повреждённый исходный JPEG товара `306608456632` полноценным оригиналом |

В исходных данных есть недоступные ссылки (`/londonskieshtori` и путь с пробелом), расхождения условий и числа тканей в наличии. Их коммерческую актуальность должен подтвердить владелец.

## Перед размещением

Выполнить `npm ci`, `npm test`, `npm run build` и `npm run qa:cms`. Сохранить рабочее хранилище CMS и настроить сервер по [инструкции](CMS.md). Браузерная проверка CMS использует временную базу; она не подтверждает работу внешней почты, оплаты или размещённого сайта.

Пуш в GitHub сам по себе не подтверждает развёртывание сайта.
