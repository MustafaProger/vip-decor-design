## Состав и сохранность

В четырёх формах цели отправляются после подтверждения сохранения сервером.
Контактные события обрабатываются в публичной части приложения, включая
динамические меню, модальные окна, подвал и содержимое страниц. Повторный
серверный ID не порождает вторую цель в работающем приложении. Ошибки Метрики
перехватываются и не влияют на формы или переходы.

Проверка до публикации выявила отсутствие счётчика на восстановленном сайте.
Пользователь отдельно согласовал однократное подключение существующего
**67314823**. Новые счётчики и цели не создавались. Инициализация ограничена
публичными страницами vip2d.ru/www.vip2d.ru; отдельный вход в `/admin` и
локальные предпросмотры исключены.

Исходники шести изменённых компонентов на VPS совпадали с базовой локальной
версией. Отличия в серверных тестах и файле `deploy/backup.sh` сохранены.
Релиз создан копированием действующего каталога и наложением 42 проверенных
файлов исходников/сборки. Хешированные ресурсы предыдущей версии оставлены для
уже открытых вкладок. Серверный код, настройки служб и рабочие данные не
перезаписывались.

До переключения выполнена согласованная резервная копия:
`/var/backups/vip-decor/20261029T164057Z`, результат `success`.
Переключение `current` атомарное; процедура имела автоматический откат при
ошибке первоначальной проверки. Сразу после публикации содержимое всех

## Условия проверки

Прямое подключение Chrome к серверу из текущей сети периодически завершалось
таймаутом. Для origin использовались реальные HTTPS-ответы действующего VPS
через интерфейс en0 с проверкой TLS и исходным доменным именем. Содержимое
страниц и публичных API не заменялось локальными данными.

Пользователь отдельно разрешил четыре реальные тестовые заявки с пометкой
«ТЕСТ МЕТРИКИ — НЕ ЗВОНИТЬ», вымышленными контактами и штатными почтовыми
уведомлениями. Журнал `real-inquiries-journal.json` записывается до каждого
POST и сразу после ответа; повторная отправка с новым ID при неопределённом
результате запрещена.

Первоначальный тестовый транспорт для пустого POST Метрики и прямое
подключение браузера не обеспечили подтверждение ответа четырёх событий.
Исправлены только обработка заголовков, пустого тела POST и редиректов в
проверочном инструменте. Это не потребовало изменения кода сайта.
Диагностические повторные проверки выделены в отчётах; они не создают
дополнительные заявки. Выполнено 13 тестовых вызовов целей: девять основных
и четыре диагностические перепроверки. В статистике могут присутствовать
дополнительные тестовые достижения `lead_project`, `lead_selection`,
`lead_calculator` и `click_phone` из-за этих перепроверок.

Локальное хранилище сертификатов не подтвердило два вспомогательных рекламных
домена Яндекса (`hdrc.yandex.net`, `mdd.yandex.net`); проверка TLS не отключалась.
Основной скрипт и коллектор Метрики отвечали успешно.

HTTP-ответ коллектора Метрики подтверждает приём запроса, но не появление
достижения в агрегированных отчётах. Кабинет счётчика 67314823 в текущей
браузерной сессии возвращает **403 — нет доступа**; права и учётные записи
не менялись.
