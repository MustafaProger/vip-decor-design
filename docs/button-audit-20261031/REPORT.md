## События для Метрики и Директа

Существующий код вызывает счётчик **67314823**. Четыре события заявок: `lead_project`, `lead_selection`, `lead_calculator`, `lead_cart`. Пять контактных событий: `click_phone`, `click_whatsapp`, `click_telegram`, `click_max`, `click_email`.

Открытие окна, переход по шагам, добавление товара и открытие оформления не считаются заявками. Контактные клики не подтверждают состоявшийся звонок или отправку сообщения. Наличие самих целей в кабинете Метрики и привязка к Директу здесь не проверялись.

Для оптимизации рекламы предлагается использовать четыре сохранённые заявки, а клики контактов рассматривать отдельно. Для сравнения конкретных кнопок потребуется дополнительная разметка: сейчас вызов `reachGoal` передаёт только имя цели, без параметров кнопки.

Настройка идентификаторов: [официальная инструкция Яндекса](https://yandex.ru/support/metrica/ru/general/goal-js-event).
