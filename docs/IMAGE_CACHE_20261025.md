При замене изображения необходимо использовать новый URL/имя файла (обычная загрузка CMS уже создаёт новое имя). Если перезаписать файл по прежнему URL, свежий браузерный кэш может показывать прежнюю версию до 7 дней. После истечения срока валидаторы проверяют изменение. Первое посещение и принудительное обновление браузера могут скачивать фото заново.
