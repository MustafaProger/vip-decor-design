# Отзывы VIP Decor Design: источник и проверка

Дата сверки: **15 сентября 2026 года**.

## Полнота

- Организация: VIP Decor Design, Яндекс ID `223039913433`.
- Источник показывает **71 отзыв**, **75 оценок**, рейтинг **5,0**.
- Получены **все 71 отзыв из 71**: 50 с первой страницы, 21 со второй.
- Проверка ключа `author + date` дала 71 уникальную запись без пересечений между страницами.
- Каждая из 71 записи содержит реальную оценку 5. Отбор по положительным оценкам не применялся.

На сайте опубликованы автор, исходная дата, оценка, краткая дословная выдержка и ссылка на полный оригинал. Даты сохранены с часовым поясом в ISO-формате и отображаются в `Europe/Moscow`. Орфография авторов в выдержках сохранена. Длинные отзывы не перепечатаны целиком.

## Публичные источники

1. [Первая страница отзывов](https://yandex.ru/maps/org/vip_decor_design/223039913433/reviews/). Данные из JSON, опубликованного внутри HTML обычной страницы. Параметры Яндекса: `offset: 0`, `limit: 50`, `count: 71`, `loadedReviewsCount: 50`, `page: 1`, `totalPages: 2`, `reviewsRemained: 21`.
2. [Вторая страница отзывов](https://yandex.com/maps/org/vip_decor_design/223039913433/reviews/?page=2). Получена через штатный браузер, извлечение из DOM `.business-review-view`, включая `meta[itemprop=datePublished]` и `meta[itemprop=ratingValue]`. Загружен 21 отзыв.
3. [Официальный виджет Яндекса](https://yandex.ru/maps-reviews-widget/223039913433?comments). Независимо подтвердил рейтинг, количество отзывов и оценок. Сам виджет показывает лишь пять текстов.

Часть запросов headless-браузера возвращала `limited`, веб-поиск — капчу. Капча не решалась и не обходилась. Обычный браузер открыл публичную вторую страницу штатно.

## Идентификаторы и ссылки

Основной файл: `src/data/yandex-reviews.json`.

- Первые 50 записей имеют `idType: yandex` и настоящий `reviewId` из источника.
- Для последних 21 записи поле `idType: local`: локальный стабильный идентификатор получен из SHA-256 имени и полной ISO-даты. Это не идентификатор Яндекса.
- У 67 авторов в DOM есть публичный профиль. Шаблон индивидуальной ссылки проверен штатным действием «Поделиться» для автора ekaterina: `https://yandex.com/maps/org/223039913433/reviews?reviews%5BpublicId%5D=...&utm_source=review`. Значение `publicId` соответствует последнему сегменту публичной ссылки автора.
- У четырёх авторов публичная ссылка отсутствует: Мария С. на первой странице; Рабаданова Хадижа, Unknown n и Цебриков Сергей на второй. Их карточки ведут на соответствующую страницу с оригиналом. При повторной сверке 15.09.2026 исправлена прежняя ошибочная ссылка Марии С. с пустым `publicId`: `/maps/user/` не является публичным профилем.
- Все тексты оформлены как выдержки до 24 слов из каждого отдельного авторского отзыва. Для коротких отзывов приведён полный текст. Источник каждой записи доступен по ссылке.

Этот документ описывает исходный проверенный снимок на указанную дату. 15.09.2026 добавлено серверное обновление раз в 24 часа: первый полный импорт успешно сохранил 71 отзыв и 79 фотографий. Для обоих листов текущий загрузчик использует JSON из публичного HTML; прежние стабильные идентификаторы сохраняются при сопоставлении. Сайт получает актуальный полный кэш через `/api/reviews`, исходный снимок остаётся резервным. Подробности, условия запуска сервера и проверка: [REVIEWS_DAILY_SYNC.md](REVIEWS_DAILY_SYNC.md).

Получены **79 фотографий из 44 отзывов**. У остальных 27 отзывов нет фотоприложений: для них сохранён пустой массив `photos`, без подстановки чужих работ.

### Как проверена принадлежность фотографий

- Первая страница: для каждой записи использован массив `reviewResults.reviews[].photos` из `work/reviews/maps.html`. Запись сопоставлена по настоящему `reviewId`; у каждого вложения дополнительно проверено совпадение `copyright.publicId` с `author.publicId` данного отзыва.
- Вторая страница: повторно открыта [страница 2 отзывов](https://yandex.com/maps/org/vip_decor_design/223039913433/reviews/?page=2). Из каждого отдельного DOM-элемента `[itemprop=review]` взяты имя, полная ISO-дата и только изображения `.business-review-media__item-img` внутри этого же отзыва. Карусели просмотрены в DOM полностью; все 11 вложений учтены.
- На второй странице фотографии прикреплены к отзывам: Рабаданова Хадижа (3), габибат а. (1), гулмира Атабаева (2), Unknown n (1), Хадижат Катаева (1), Никита Черкасов (1), Патимат Рабаданова (1), x3m4k (1).
- Сопоставление не выполнялось только по имени: в наборе есть два автора «Марина Б.». Для записей без публичного профиля использованы имя и точная ISO-дата отзыва.
- Все 79 изображений просмотрены на контактных листах: шторы, жалюзи, ткани, карнизы и другие результаты работ. Порядок вложений сохранён, первый элемент массива можно использовать как обложку отзыва.

### Формат данных и доставка

```ts
photos: Array<{
  src: string;       // /images/reviews/work-<yandexPhotoId>.webp или /api/review-media/<sha256>.webp
  sourceUrl: string; // исходный URL вложения Яндекса
  width: number;    // фактическая ширина WebP
  height: number;   // фактическая высота WebP
}>;
```

Файлы загружены из `get-altay`, по URL соответствующего вложения, в размере `orig`. Для фотографии урмилы курбановой (`13299246_2a0000018e478c9d812685bf7e6ea2fb18b4`) источник `orig` вернул повреждённый JPEG; использована исправная версия `XXXL` того же изображения Яндекса. Этот URL сохранён в `sourceUrl`.

Для сайта подготовлены WebP-копии: максимум 1400 px по большей стороне, качество 82, без увеличения маленьких исходников. Учтён EXIF-поворот; кадрирование, ретушь и генерация не применялись.

Общий объём 79 WebP-файлов — **9 435 492 байта**, исходных файлов — 58 228 501 байт. Все файлы успешно декодируются, имеют 79 разных SHA-256, размеры совпадают с JSON. Число и порядок вложений каждого отзыва совпадают с источником. В папке остались ровно 79 файлов `work-*.webp`; фотографий профилей и ссылок на них в данных больше нет.

Проверка также подтвердила сохранность текстов, имён, дат, оценок и идентификаторов всех 71 отзывов. Проверка нового интерфейса выполняется отдельно.

Полные длинные тексты не добавлялись; исходные выдержки, даты, оценки и идентификаторы всех 71 отзывов сохранены. Полный оригинал открывается по индивидуальной ссылке отзыва или странице источника.
