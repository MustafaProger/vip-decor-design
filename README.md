# VIP DECOR DESIGN

Рабочая локальная версия редизайна по комплекту `design-concept/`. React 19, TypeScript, Vite. Концепция «Фактура. Свет. Тишина.» реализована живыми компонентами; исходные макеты и архив оставлены на месте.

## CMS

Панель `/admin` управляет статьями, каталогом и заявками. Изменения сохраняются в серверной базе; почта пока не подключена. [Первый вход, работа, резервные копии и запуск на сервере](docs/CMS.md). Нужен Node.js 24.15 или новее.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://127.0.0.1:5180/. Команда запускает интерфейс на 5180 и локальный сервер заявок на 3001. Порт 5173 оставлен существующему приложению пользователя.

```bash
npm run build     # TypeScript и production-сборка в dist/
npm test          # цены, варианты, целостность расчётов и локальный сервер
npm run qa        # браузерная проверка; требует запущенного npm run dev и Chrome
npm run qa:redesign # анимации, галерея и страницы компании на 320–1920 px
```

`npm run preview` показывает production-сборку на 4173. Для форм дополнительно нужен `node server/index.mjs` (порт 3001).

## Что реализовано

- Главная, все направления, каталог с поиском, фильтрами по категории/цвету/цене, сортировкой, чипами и сохранением параметров в URL.
- 477 уникальных исходных товаров: фотографии, описания, артикулы, варианты, старые цены и буквальные надбавки из Tilda. Два товара без цены сохраняют это состояние.
- Карточка товара, переключение варианта, оригинальные товарные URL, избранное и корзина, сохраняющиеся в браузере отдельно друг от друга.
- Четыре шага подбора: комната, материалы, размеры и контакты. Возврат сохраняет ответы. Источник концептуального проекта включается в заявку.
- Прежний калькулятор с исходной формулой, тарифами и округлением; проверен на живом исходнике.
- 28 уникальных исходных фотографий работ, галерея с просмотром, отдельная маркированная концепция «Тихая гостиная».
- Исходные информационные страницы, услуги, прайс, условия, политика, контакты, дополнительные фотографии и социальные ссылки.
- Локальный сервер заявок с проверкой данных, согласия и источника запроса, ограничением размера, сохранением на диск и защитой от повторных записей.
- Шесть адаптивных ширин 320–1920 px, меню/диалоги с Escape и возвратом фокуса, reduced motion, локальные шрифты и лицензии OFL.

`src/data/site-content.json` — архивный нормализованный снимок для первого импорта CMS. Дальнейшие правки выполняются через `/admin`. Публичный каталог читает `/api/content`; старый адрес `/data/site-content.json` также отдаёт актуальные данные CMS. `data/source/` содержит исходные HTML, JSON API, оригинальные изображения и результаты проверки. `public/source-media/` — локальные оптимизированные изображения. Изображения из `public/images/concept-*` — созданные концепции, на страницах они подписаны.

Повторная выгрузка (перезаписывает нормализованный снимок; сначала сохраните свои редакторские изменения отдельно): `python3 scripts/crawl_source.py`, `python3 scripts/crawl_refine.py`, `node scripts/crawl_optimize_media.mjs`, `python3 scripts/crawl_verify.py`. Python-зависимости: `requests`, `beautifulsoup4`. Скрипты только читают публичный сайт, не отправляют формы.

## Граница локальной версии

Полный production-перенос **не завершён**: Tilda CRM/обработчики форм, синхронизация актуальных остатков и цен, действующие промокоды, создание настоящего заказа и оплата пока не подключены. Интерфейс это прямо сообщает. Формы сохраняют обращения в CMS; они доступны администратору в разделе «Заявки». Почтовых уведомлений нет. Для совместимости API возвращает `saved_locally`. Корзина сохраняет запрос, не создаёт оплаченный заказ.

Заявки содержат персональные данные: журнал `data/runtime/inquiries.jsonl` сохраняет исходные обращения, а база CMS хранит их копии, статусы и заметки. Вся папка `data/runtime` исключена из Git. Путь можно изменить `INQUIRY_DATA_DIR`; адрес допустимого интерфейса — `APP_ORIGIN`; порт сервера — `INQUIRY_PORT`. Для реального обработчика задан контракт `POST /api/inquiries`; `VITE_INQUIRY_ENDPOINT` позволяет подключить совместимый endpoint. Токены и ключи в frontend не помещаются.

В источнике есть две недоступные ссылки (`/londonskieshtori`, путь с пробелом), один обрезанный JPEG товара `306608456632`, расхождения условий и чисел наличия. Они зафиксированы в реестре, а коммерческие сведения самовольно не исправлены. Публикация и изменение действующего vip2d.ru не выполнялись.

## Обновление интерфейса 12 сентября 2026

«О компании» находится на `/company`; старый `/studio` перенаправляет с сохранением якоря. Страницы компании и штор используют смысловые React-компоненты: цифры, рассказ о компании, преимущества, этапы заказа и замер. Общие блоки находятся в `src/components/ServiceSections.tsx`, оформление — в `src/pages/editorial.css`. Остальные информационные страницы получают нормализованные абзацы и заголовки без пустых контейнеров старой вёрстки.

Framer Motion отвечает за появление первого экрана и разделов при прокрутке, открытие диалогов, смену фото и отклик отдельных кнопок. Общие реакции при наведении описаны в `src/interactions.css`. `MotionConfig` и `useReducedMotion` учитывают системную настройку уменьшенного движения; отключаются также CSS-перемещения. [Документация Motion](https://motion.dev/docs/react-accessibility).

В `src/data/gallery-presentation.ts` подписи и границы кадрирования привязаны к именам исходных файлов. `Picture` показывает нужную область через SVG viewBox: белые поля, декоративные рамки и чёрные полосы скрыты, исходные изображения не перезаписываются. В диалоге показывается вся область кадра без дополнительного обрезания.

Отчёт новых сценариев и снимки desktop/mobile: `docs/qa-redesign/`. Общая проверка всех маршрутов и доступности: `docs/BROWSER_QA.md`.
