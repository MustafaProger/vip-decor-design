# VIP DECOR DESIGN — iOS 27 / Liquid Glass

Подготовлено 15 сентября 2026 года.

## Передача исполнителю

Передайте репозиторий, `PROMPT_FOR_REBUILD.md` и три PNG. В промпте уже описаны полный редизайн, восстановление подтверждённых пропусков, сохранение данных, адаптивность и критерии приёмки.

| Файл | Назначение |
| --- | --- |
| `01-contacts.png` | Контакты: интерьер, адрес, маршрут, телефоны, обращение |
| `02-price.png` | Прайс: категории услуг, строки цен, расчёт |
| `03-fabric-guide.png` | Гид: помещения, наглядные рекомендации, подбор |
| `PROMPT_FOR_REBUILD.md` | Единый промпт для реализации |
| `IMAGE_PROMPTS.md` | Точные описания для повторной генерации |

## Что проверено

Изучены три исходных скриншота, маршрутизация, общий шаблон информационных страниц, локальные данные и документы проекта. В текущем JSON — 41 исходная страница, 36 категорий, 477 товаров. `/contacts` и `/price` имеют отдельные компоненты; `/kakpodobrat` выводится общим `Information` через импортированные блоки. Это объясняет необходимость структурной переработки части контента.

Полный обход текущего сайта для установления всех отсутствующих страниц в рамках подготовки концепции не выполнялся. Такой обход и таблица доказанных пропусков входят в промпт для реализации. Приложение не переписывалось; созданы только материалы этой папки.

## Как читать изображения

Все три макета — концепции интерфейса, созданные встроенным image_gen. Фотографии не подтверждают существующий интерьер шоурума или выполненные работы; карта схематична. Тексты и числа из данных проекта имеют приоритет над изображениями. В частности, случайную подпись «Более 1000 коллекций в шоуруме» на макете контактов не переносить без подтверждения. Декоративные лозунги на полях не обязательны.

Прайс в макете показывает лишь часть исходных позиций; остальные необходимо сохранить в реализации. Ткани на макете гида не являются подтверждёнными товарными рекомендациями.

Общая основа — жемчужный фон, тёмно-зелёный акцент, прозрачная навигация, крупные фотографии и читаемые поверхности для данных. Между генерациями есть небольшие различия логотипа и пропорций шапки: в коде нужен один компонент с действующим фирменным знаком. Стиль «iOS 27» интерпретирован как художественное направление на основе Apple Liquid Glass, адаптированное к интерьерному сайту.
